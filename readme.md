# Инструкция по запуску проекта

## 1️ Установка npm

Убедитесь, что у вас установлен **Node.js** и **npm**.  

## 2️ Запуск проекта

Выполните команду для запуска проекта:

```bash
npm start
```

## 3️ Настройка базы данных

Используйте один из предоставленных файлов для установки БД:

- dump1.sql - SQL дамп базы данных

- dumb2.backup - Backup файл базы данных

## 4️ Настройка подключения к БД

В файле конфигурации Spring (application.properties) настройте подключение:

```properties
spring.datasource.url=your_database_url
spring.datasource.username=your_username
spring.datasource.password=your_password
```

## 5 Настройка Токена Бота
Необходимо указать токен Telegram-бота в поле BOT_TOKEN в классе src\main\java\hackathon\fluttershy\front\TelegramBot.java
